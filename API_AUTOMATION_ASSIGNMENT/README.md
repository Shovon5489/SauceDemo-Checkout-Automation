## API Automation (Postman + Newman)

### What is covered

All requests live in one Postman collection and run **sequentially**. Data captured in earlier requests is stored in collection variables and reused later.

| # | Request | Method | Endpoint | What is verified |
|---|---------|--------|----------|------------------|
| Q3 | Login | `POST` | `/login` | Status `200`; `token` is present and saved as `authToken` |
| Q4 | Get User | `GET` | `/users/{userId}` | Status `200`; user id, first name and email match; name and email stored for later |
| Q5 | Put Profile | `PUT` | `/users/{userId}` | Status `200`; `updatedAt` exists and is recent; updated values returned |
| Q6 | Patch Single Field | `PATCH` | `/users/{userId}` | Status `200`; only the patched field is returned; `updatedAt` exists |
| Q8-1 | Login Missing Password | `POST` | `/login` | Status is `4xx`; error message present |
| Q8-2 | Login Missing Email | `POST` | `/login` | Status is `4xx`; error message present |
| Q8-3 | Login Unregistered User | `POST` | `/login` | Status is `4xx`; error message present |
| Q8-4 | Register Missing Password | `POST` | `/register` | Status is `4xx`; error message present |
| Q8-5 | User Not Found | `GET` | `/users/9999` | Status is `404` |

**Response code validation:** every request asserts its response status code.
**Total assertions:** 22.

### Collection variables

Configured inside the collection (no separate environment file needed):

| Variable | Purpose |
|----------|---------|
| `baseUrl` | `https://reqres.in/api` |
| `userId` | User used for Q4 to Q6 (`2`) |
| `apiKey` | Sent as the `x-api-key` header |
| `authToken` | Set automatically by Q3 |
| `firstName`, `email` | Set automatically by Q4, reused in Q8 |

> The `apiKey` in the collection is a free ReqRes demo key. To use your own, sign in at [app.reqres.in](https://app.reqres.in/documentation) and replace the value of the `apiKey` collection variable.

### Prerequisites

- [Node.js](https://nodejs.org/) (LTS or newer)

```bash
npm install -g newman newman-reporter-htmlextra
```

### How to run

From the repository root:

```bash
newman run Api_automation_Assignment.postman_collection.json
```

Run and generate the HTML report:

```bash
newman run Api_automation_Assignment.postman_collection.json -r cli,htmlextra --reporter-htmlextra-export reports/api-report.html
```

### Expected result

```
assertions: 22 executed, 0 failed
```

### Run in Postman (optional)

1. Import `Api_automation_Assignment.postman_collection.json` into Postman.
2. Select **No Environment**.
3. Open the collection, click **Run**, keep the order Q3 → Q4 → Q5 → Q6 → Q8-1 … Q8-5, then **Start run**.

## Notes

- Requests run in a fixed order because later requests depend on data from earlier ones.
- ReqRes is a mock API: `PUT` and `PATCH` responses are echoed back and not persisted, so the checks compare against the data sent in each request.
- Node.js and Newman are the only requirements for running the API tests locally.
